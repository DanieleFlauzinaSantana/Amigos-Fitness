# **App Name**: Academia Inteligente

## Core Features:

- Profile Management: User profile creation and management with fields for personal information, emergency contacts, and fitness goals.
- Daily Check-in: Daily check-in feature to record attendance.
- Dropout Prediction: AI-driven prediction model to forecast potential early dropouts based on attendance patterns and user profile data.
- Absence Notifications: Automated notifications to students who have missed classes, encouraging them to return and stay engaged.
- Satisfaction survey: Customizable survey sent out via email and other communication channels such as WhatsApp. Students complete it, providing critical feedback to gym managers and operators

## Style Guidelines:

- Primary color: A deep purple (#673AB7), reflecting the creativity of physical movement as well as consistency and quality of service.
- Background color: A light grey (#F5F5F5) for a clean, open feel.
- Accent color: A bright blue (#3F51B5), providing highlights and attracting attention.
- Use of modern sans-serif fonts.
- Simple, clear icons for easy navigation.
- Clean, card-based layouts.
- Subtle transitions.
